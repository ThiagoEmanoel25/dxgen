# RAG scan + chunk benchmark — 2026-11-16

## Scope and protocol

This benchmark measures only credential-free repository scanning, file reads, recursive character chunking, metadata creation, and JSON serialization. It does not call OpenAI, Pinecone, or an LLM.

- Rust release build; schema v1 output compared after sorting by `(relativePath, chunkIndex)`.
- Three warmups and twenty measured runs, alternating implementation order.
- Filesystem-warm caches; process startup is included.
- Corpus: the committed analyzer fixture (7 chunks) and the stable DXGen `packages/` subtree (164 chunks). The repository root is intentionally excluded so the result files cannot become part of their own corpus.
- Raw result: `docs/benchmarks/2026-11-16-rag.json`.

## Environment

- Machine: Apple M1 Pro, 10 logical cores, 32 GiB memory
- OS: macOS 26.4.1, arm64
- Node: v24.21.0; npm: 11.19.0
- Rust: rustc 1.100.0
- Source state: working tree based on `cd789411f961abc34d2b06323538bb22c0c804c4`
- Rust binary: 2,041,888 bytes; Node executable: 247,417,680 bytes, excluding JavaScript dependencies

## Correctness

- `npm run test:rag-parity` passed on the committed fixture and a generated Unicode/overlap fixture.
- Normalized output matched exactly on both benchmark corpora: chunk IDs, text, source/relative paths, indices/counts, line ranges, file type, and semantic flags.
- DXGen packages normalized output SHA-256: `b463823ce7a82d7ae32cdcb54c58bcd95a942a68dcb8c2efca0c8d7b0318581f`.
- Order is normalized because Globby traversal order is filesystem-dependent; Pinecone IDs and metadata do not depend on insertion order.

## Results

| Corpus | Implementation | Median wall | p95 wall | Median CPU | Peak RSS |
|---|---|---:|---:|---:|---:|
| Fixture | TypeScript | 294.19 ms | 343.66 ms | 490 ms | 126.0 MiB |
| Fixture | Rust | 6.18 ms | 8.76 ms | <10 ms | 3.3 MiB |
| DXGen packages | TypeScript | 303.14 ms | 377.62 ms | 490 ms | 127.7 MiB |
| DXGen packages | Rust | 11.67 ms | 13.27 ms | <10 ms | 4.8 MiB |

## Decision

The Phase 4 local-work gate passes. On DXGen packages, Rust reduced median wall time by 96.1% and peak RSS by 96.2%; the small fixture improved rather than regressed. Adopt native default scan + chunking behind the versioned adapter and retain TypeScript for all network/provider work and as the compatibility fallback.

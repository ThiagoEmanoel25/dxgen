## Protocol

- Rust release build.
- Three warmups and twenty measured runs per implementation and repository.
- TypeScript/Rust order alternates on every warmup and measured run.
- Filesystem-warm results; OS caches are not cleared.
- Process startup, scanning, file reads, analysis, and JSON serialization are included.
- Correctness requires identical discovered-file manifests and normalized output.

## Decision

- Gate passed: **yes**.
- Correctness: 100% on file manifests and normalized output for the recorded corpus.
- Medium median reduction: 91.9%; large median reduction: 96.4%.
- Medium peak-RSS reduction: 94.0%; large peak-RSS reduction: 79.7%.
- Small-repository median did not regress; it fell by 98.2% at the timer's recorded precision.
- The release binary runs directly without Node and missing-path failures remain actionable.
- Decision: proceed to Phase 2, integrating the Rust analyzer behind the TypeScript CLI boundary without changing generated output.
